# Fotografije za meni

Ubacite JPG fotografije u ovaj folder sa tačno ovim imenima. Slika koja ne postoji
automatski se zamenjuje ikonicom, pa možete dodavati jednu po jednu.

| Fajl | Gde se prikazuje |
|---|---|
| `cover.jpg` | Velika naslovna fotografija (enterijer, bašta, šank) |
| `akcija.jpg` | Akcija: Espresso + Coca-Cola |
| `kategorija-kafa.jpg`, `kategorija-topli.jpg`, `kategorija-sladoled.jpg`, `kategorija-shake.jpg`, `kategorija-prirodni.jpg`, `kategorija-negazirani.jpg`, `kategorija-gazirani.jpg`, `kategorija-energetski.jpg`, `kategorija-voda.jpg`, `kategorija-pivo.jpg`, `kategorija-vino.jpg`, `kategorija-kokteli.jpg`, `kategorija-zestoko.jpg` | Pločice kategorija |
| `espresso.jpg`, `cappuccino.jpg`, `latte.jpg`, `ice-coffee.jpg`, `frape.jpg`, `caj.jpg`, `topla-cokolada.jpg` | Kafa, čaj, čokolada |
| `sladoled.jpg`, `ice-coffee-sladoled.jpg`, `vocni-kup.jpg`, `banana-split.jpg` | Sladoled |

Trenutne fotografije su besplatne stock fotografije (CC0 / javni domen), spisak izvora je u `CREDITS.md`. Zamenite ih pravim fotografijama kafića kad ih budete imali, sa istim imenom fajla.

Preporuka: kvadratne ili 4:3 fotografije, oko 1200 px, do 300 KB.
Da bi se fotografija prikazala i uz neku drugu stavku, dodajte joj `img: "ime-fajla"` u `MENU` u `index.html`.
Instagram link se uključuje u `SETTINGS.instagram` na vrhu skripte u `index.html`.
